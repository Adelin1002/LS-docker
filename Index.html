Référence pratique

Les commandes essentielles

Les commandes les plus utilisées au quotidien pour administrer tes conteneurs.

🚀

1. Démarrage et arrêt des services

Lancer et arrêter ton application

Démarrer les services

Lance tous les services en arrière-plan.

docker compose up -d

-d signifie detached (arrière-plan).

Arrêter les services

Arrête et supprime les conteneurs et réseaux du projet.

docker compose down

Les volumes ne sont pas supprimés par défaut.

🔨

2. Construction des images

Construire ou reconstruire les images Docker

Construire les images

Construit les images définies dans le fichier Compose.

docker compose build

Reconstruire sans cache

Force une reconstruction sans utiliser le cache de build.

docker compose build --no-cache
🔍

3. Gestion et inspection

Surveiller et administrer les conteneurs

Afficher l'état des services

docker compose ps

Afficher les logs en temps réel

docker compose logs -f

Exécuter une commande dans un service

docker compose exec <service> <commande>

Exemple : docker compose exec backend python manage.py migrate

📈

4. Mise à l'échelle

Augmenter le nombre d'instances d'un service

Démarre trois instances du service web.

docker compose up --scale web=3 -d

Attention : le service doit pouvoir fonctionner avec plusieurs instances. Évite de publier directement le même port fixe pour chaque réplique.

📂

5. Plusieurs fichiers Compose

Combiner plusieurs configurations

Spécifie plusieurs fichiers YAML. Ils sont fusionnés dans l'ordre indiqué.

docker compose -f compose.yml -f compose.override.yml up

Les fichiers suivants peuvent remplacer ou compléter les paramètres précédents.

Configuration

6. Options utiles

OptionDescription
--env-file Définir un fichier de variables d'environnement.
-p / --project-name Définir le nom du projet Compose.
--profile Activer un profil spécifique.
--progress Contrôler l'affichage de la progression : auto, tty, plain, json, quiet.

Application pratique

Exemple de fichier compose.yaml

Un exemple minimal utilisant le serveur web Nginx.

compose.yaml 
services:
  web:
    image: nginx:latest
    ports:
      - "8080:80"

Explication

  • • services : déclare les services de l'application.
  • • web : nom du service.
  • • image : image Docker utilisée.
  • • ports : redirige le port 8080 de l'hôte vers le port 80 du conteneur.

Accès au serveur : http://localhost:8080

En pratique

Cycle de travail Docker Compose

2

Démarrer l'application

3

4

Consulter les journaux

docker compose logs -f
5

Arrêter l'application

docker compose down
💡

Conseil important

La commande docker compose down -v supprime également les volumes déclarés dans le projet. Attention : cela peut entraîner la perte des données persistées, notamment celles d'une base PostgreSQL.
